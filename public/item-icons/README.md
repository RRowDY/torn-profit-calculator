Put your custom item images in these folders:

- `public/item-icons/plushies/`
- `public/item-icons/flowers/`

Recommended naming style:

- Lowercase
- Spaces replaced with hyphens
- `.png` format

Examples:

- `public/item-icons/plushies/camel-plushie.png`
- `public/item-icons/flowers/cherry-blossom.png`
